# Лабораторная работа №9. Функции

Скрипт запускается в личной копии PostgreSQL «Учет на складе». Для заданий 3 и 4 нужна таблица `log_file` из примеров.

1. **Количество операций поставщика.** `agent_operation_count` считает строки по коду поставщика и типу операции. Запрос сравнивает число операций `R` каждого поставщика с результатом «Надежного».

2. **Код товара в результате.** `goodsbyagent_2` возвращает код, название и число операций с каждым товаром. В запросе с единицей измерения таблицы соединяются по `id_goods`.

3. **Нумерация строк.** `goodsbyagent_3` сортирует товары по названию и коду, увеличивает номер в цикле и выдаёт каждую строку через `return next`. Названия товаров также записываются в журнал. Пример вызова — `select * from goodsbyagent_3('Надежный');`

4. **Строка «ИТОГО».** `goodsbyagent_4` в цикле суммирует количество операций и после списка товаров добавляет строку с итогом. Для поставщика без операций итог равен нулю. Пример вызова — `select * from goodsbyagent_4('Надежный');`

5. **Оборот за период.** `goods_turnover` включает обе граничные даты. Количество из операций `A` суммируется в приход, из `R` — в расход. Если по товару был только один тип операций, во втором столбце будет ноль. Пример вызова — `select * from goods_turnover('2006-01-01', '2007-12-31');`

6. **Количество пропущенных значений.** `count_nulls` принимает имя таблицы и столбца и считает строки с `null`. `regclass` находит таблицу по имени, а `%I` в `format` экранирует имя столбца. Пример вызова — `select count_nulls('agent', 'phone');`

7. **Минимум и максимум по группам.** `grouped_min_max` группирует строки по первому столбцу и применяет `min` и `max` ко второму. Значения переводятся в текст после вычисления, поэтому числа сравниваются как числа, а даты — как даты. Пример вызова — `select * from grouped_min_max('operation', 'typeop', 'price');`
