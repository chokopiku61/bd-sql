# Лабораторная работа №7. Изменение данных и подзапросы

В начале ЛР7 нужно создать личную базу, открыть для неё отдельное соединение и загрузить выданный преподавателем `dump_wh_new.sql`. В этом проекте дампа нет. `lab-7.sql` запускается в уже подготовленной личной копии «Учет на складе».

В конце скрипта `rollback` отменяет изменения в таблицах. Тестовые операции для заданий 9, 10 и 12 откатываются сразу после соответствующего запроса через `savepoint`. Значения последовательностей при откате не возвращаются.

1. **Новые склады.** Добавил два склада. Первый используется при добавлении операций. Второй остаётся пустым для проверки задания 6.
2. **Остаток и операция.** По названиям «Папки», «Склад ЛР7» и «Астра» подзапросы находят нужные коды для вставки.
3. **Цена и количество операции.** Три условия по найденным кодам выделяют операцию, добавленную в задании 2.
4. **Цена операций поставщика.** Подзапрос находит код «Астры». `update` меняет цену во всех её операциях.
5. **Агенты без операций.** `not exists` проверяет, есть ли у каждого агента хотя бы одна операция.
6. **Пустые склады.** Два условия `not exists` проверяют отсутствие строк и в `goods_wh`, и в `operation`.
7. **Товары без операций.** Для каждого товара проверяется, что его код не встречается в `operation`.
8. **Поставщики с одной операцией.** Операции сгруппированы по поставщику. `having count(*) = 1` оставляет нужные группы.
9. **Товары с наибольшим числом операций.** Для проверки два лидера доводятся до одного счётчика. `>= all` выбирает каждый товар, чей результат не меньше любого другого.
10. **Поставщики папок по максимальной цене.** Добавил две поставки по текущей максимальной цене папок среди операций типа `A`. Подзапрос с `max` позволяет вернуть всех поставщиков с этой ценой.
11. **Поставщики, работающие с несколькими складами.** `count(distinct id_wh)` считает склады, с которыми работал поставщик.
12. **Товары с одним поставщиком.** У тестового поставщика две операции с одним товаром. `count(distinct id_ag)` учитывает его один раз.
13. **Самые частые поставки «Астры».** Для этого поставщика считаются операции типа `A` по товарам. При равенстве максимумов выводятся все лидеры.
14. **Товары на складе на Шолохова.** Вложенные `in` сначала находят код склада, затем коды товаров из его остатков.
15. **Склады с поставками бумаги для факсов.** Вложенные `in` находят код товара и склады с его операциями типа `A`.
